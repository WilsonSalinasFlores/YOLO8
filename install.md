# **Instalar Liberias**

## 1. Installar UltraAnalytics
Se debe instalar ultra analitics es un marco de trabajo de IA de visión por computadora, desarrollado por Ultralytics, que se centra en la detección de objetos y la segmentación de imágenes en tiempo real, basado en la arquitectura YOLO

``pip install ultralytics``

## 2. Instalar opencv
OpenCV para la manipulación de imágenes y videos, así como para visualizar los resultados de la detección.

``pip install opencv-python``

## 3. Instalar PyTorch (Opcional Uso de GPU/CPU) 
Esta instalación es opcional es para el uso del CPU o memoria

``pip install opencv-python``

* ### Para uso de CPU: 

``pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu``

* ### Para uso de GPU: 
``pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121``
